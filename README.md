## 🧠 xv6 Operating System — Study & Extension Project

### 📘 Overview

This repository contains my learning and experimental work based on **MIT’s xv6 operating system**, a simple Unix-like OS used for educational purposes in **MIT’s 6.S081 Operating Systems course**.
 Through this project, I explored the **core design and implementation of operating systems**, including process management, scheduling, interrupts, synchronization, and memory management.

### 🧩 Key Topics Covered

- 🧵 **Process and Thread Management:**
   Implemented process creation (`fork`), scheduling (`sched`), and context switching (`swtch`).
- ⏱ **Trap and Interrupt Handling:**
   Analyzed the xv6 trap mechanism, including **timer interrupts**, **system calls**, and **exception handling**.
- 🧮 **Synchronization Mechanisms:**
   Studied the role of spinlocks and sleep locks in multi-core scheduling.
- 📂 **File System and I/O:**
   Explored xv6’s file descriptors, inodes, and buffered disk I/O.
- 🧱 **Kernel-Level Programming Practice:**
   Modified and instrumented xv6 kernel source to observe process scheduling and interrupt behavior.
